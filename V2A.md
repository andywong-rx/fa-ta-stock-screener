```toml
[sec]
user_agent = "YourApplication/2A YourName your-monitored-email@your-domain.example"
```

This is an illustrative placeholder, not a configured contact. The app reads `st.secrets["sec"]["user_agent"]` server-side. For local development use the same TOML in `.streamlit/secrets.toml`, which is ignored by Git. Never commit that file or put the real value in a widget, screenshot, command argument, log or issue. The contact is not an API key, but it is private operator configuration and is sent to SEC in the HTTP User-Agent header. No contact identity is stored in the response cache. The UI reports only whether configuration is ready. Values must be printable ASCII, 12–256 characters, with an application/operator identity before an email address; CR/LF and non-ASCII header values are rejected. Missing files, invalid TOML, missing keys and malformed values produce a generic warning and disable the combined REAL refresh button, while existing cached data and DEMO remain usable. No automatic visible-field or environment fallback is used.

No paid fallback, paid key, or subscription is introduced. Streamlit Community Cloud's free service is an optional host subject to its own limits; availability is not guaranteed.

SQLite caches raw responses under `.cache/v2a.sqlite` (override with `SCREENER_CACHE`). SEC cache TTL 24h; ticker map 7d; prices 6h. Refresh requests reuse fresh cache entries. Ordinary reruns perform no external requests. Sequential one-symbol batches avoid concurrency bursts. Failures are reported separately by provider/symbol; previously successful data and its timestamp remain visible. Local disk is ephemeral on Community Cloud, is not a durable database or shared across instances, and may be deleted on reboot/redeploy. No background jobs, paid storage or paid API credentials are needed; only the private operator SEC identity is configured in Secrets. Session watchlists and rule edits can be exported as CSV; they are not durable user accounts.

SEC ticker mappings and Company Facts are schema-checked before caching or marking the response valid (including issuer CIK/name, taxonomy/unit structure, finite numeric facts, dates, form and accession). Malformed JSON, invalid fields or unexpected types fail safely and do not overwrite previous valid responses. A valid response does not imply that all nine metrics are available. Cached price/fundamental/status payloads are checked again before rendering; invalid financial fields and calculation failures remain UNKNOWN. A chart failure leaves screening values visible. Raw exception text is never shown in provider status, to prevent contact details echoed by a backend from leaking.

SQLite operations are serialized within one process. After successful writes, an atomic SQLite backup is kept beside the database. Structurally corrupted databases are quarantined (`.corrupt-*`), then restored from a readable backup or already-read process data. Damaged JSON rows can fall back to the backup with their original timestamps. If neither copy is usable, the cache starts empty and requires explicit refresh; it never synthesizes prices or financial values. Storage access/locking failures retain the disk files and use current process memory with a warning. Backup creation adds disk/IO overhead suitable for this limited single-instance pilot. The backup is local and equally ephemeral on Community Cloud; it is not off-host disaster recovery. All copies lost means data must be fetched again. Backups/quarantines remain under the ignored `.cache/` directory by default; operators may remove obsolete quarantines after preserving anything needed. Use an ignored local path if overriding `SCREENER_CACHE`.

## Fundamentals

Only USD US-GAAP facts in 10-K/10-Q and amendments filed by the cutoff are eligible. Foreign IFRS filers (e.g. TSM), custom tags and unsupported accounting presentations may be UNKNOWN. No currency/ADR conversion is guessed. Annual metrics refer to the latest supported fiscal-year revenue period, NOT latest-quarter growth. Duration must be 350–380 days; matching metric periods must share start/end. Prior years must end 350–380 days earlier and durations differ ≤8 days. Quarterly/YTD values are never mistaken for annual totals. For identical tag/start/end, latest filed fact wins, so subsequent amendments/restatements are used. This is a current reported-data screener, NOT a historical point-in-time backtester; filings have date rather than intraday acceptance precision. Provenance includes tag, unit context, fiscal dates, filing dates and accession IDs. UNKNOWN is never zero.

- Revenue growth YoY = (annual revenue / comparable prior annual revenue − 1) ×100, requiring a positive base.
- EPS growth YoY uses reported diluted annual EPS similarly; a nonpositive prior base is UNKNOWN (no misleading loss-to-profit growth percentage).
- Gross margin = annual gross profit / revenue ×100; if gross profit is absent, revenue minus matching reported cost of revenue. Positive revenue required.
- ROIC is an **approximation**: annual operating income × (1 − reported effective tax rate) / average year-end invested capital ×100. Effective tax rate = tax expense / positive pretax income, restricted to [0,1]. Invested capital = positive book equity + current long-term debt + noncurrent long-term debt − cash. Both years and every component must exist and invested capital must be positive. This deliberately narrow debt definition excludes short-term borrowings, leases and other adjustments; unsupported debt presentations yield UNKNOWN. This is not exact economic ROIC.
- Trailing P/E = dated completed Close / positive trailing diluted EPS. EPS bridge = annual EPS + subsequent fiscal YTD EPS − comparable prior YTD EPS; no quarter annualization. EPS bridge is approximate because reported per-share amounts are rounded and share weights vary. Annual EPS is used only when no subsequent EPS period is reported. If comparable YTD is unavailable, latest EPS period is over 150 calendar days old, negative EPS, missing price, or unreconciled stock split in the EPS lookback: UNKNOWN. Price/EPS calculation excludes filings dated after the price date. Other FA values are current reported annual values and may have a later filing date than a stale price.
- Forward P/E = UNKNOWN: no legitimate free forward-estimate feed is configured.
- Free cash flow = annual operating cash flow − reported nonnegative purchases of property, plant and equipment, USD (not billions). Both periods must match; absent capex is UNKNOWN.
- Debt-to-equity = reported current + noncurrent long-term debt / positive book equity. Approximate narrow debt definition as above; not net debt or debt/assets.
- Share count growth = annual diluted weighted-average shares YoY ×100, requiring a positive base. Stock splits and dilution can affect this figure; not a buyback-only measure.

## Daily technical definitions

Yahoo `auto_adjust=False`, `back_adjust=False` retains Yahoo's split-adjusted OHLC and excludes dividend total-return adjustment. Volume uses the provider's supplied convention. SPY uses the same basis, so relative strength is price return, not total return. Do not mix dividend-adjusted Close with raw highs/lows. Action records are kept for the P/E split guard. Price date is always shown. Download two years daily history; remove the entire current America/New_York calendar date, even after close, to conservatively admit only completed candles. Exchange closures naturally have no row. No interpolation, backfill or future shifts. Invalid OHLCV rejects that symbol refresh; stale saved data remains labeled. Price older than four calendar days is flagged.

- Close > SMA50 and Close > SMA200: simple arithmetic mean including the completed current bar, ≥50/200 sessions.
- SMA50 > SMA200: ≥200 sessions.
- Higher highs AND higher lows: maxima of High and minima of Low of last 20 sessions each exceed those of the preceding nonoverlapping 20; ≥40 sessions. Causal window definition, not future-confirmed pivots.
- RSI(14) 50–70 inclusive: Wilder recurrence seeded with first 14 changes (15 candles); zero gain/loss =50, gains without losses =100.
- MACD(12,26,9) line > signal: causal adjust=False EMAs, min periods 12/26 and 9 valid MACD samples (34 bars).
- 63-day relative strength = stock Close return − SPY Close return, decimal return units (0.10 =10 percentage points), ≥64 candles with exact same start/end dates; unmatched benchmark dates yield UNKNOWN.
- Relative volume = current Volume / mean of previous 20 completed sessions, excluding current; ≥21 bars and positive denominator.
- Breakout: Close > maximum High of previous 20 bars, excluding current; ≥21 bars.
- OBV > its current 10-day SMA: starts at zero; signed daily volume, unchanged price adds zero; ≥10 bars. Missing volume makes OBV unknown thereafter.

The unchanged four presets, all 19 editable rules and scoring are reused. Enabled UNKNOWN metrics get zero score credit and stay in the denominator; this is a scoring penalty, never an invented financial zero. Mandatory rules gate qualification; known failures take precedence over unknown within a group. With no mandatory rules, all enabled group rules gate qualification. No enabled rules means unknown. Combined score uses the selected FA/TA weight. Forward P/E being mandatory can prevent full qualification: deliberately disable it or make it optional in a CUSTOM variant if appropriate. Scores are screening matches, not return forecasts.
